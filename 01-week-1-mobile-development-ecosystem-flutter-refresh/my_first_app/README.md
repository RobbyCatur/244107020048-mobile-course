# my_first_app

Aplikasi pertama saya yang menampilkan profil mahasiswa, dibuat sebagai latihan minggu pertama mata kuliah Pemrograman Mobile.

## Tujuan

Repository ini merupakan hasil pembelajaran ekosistem pengembangan aplikasi mobile menggunakan Flutter. Tujuannya adalah mengenalkan dasar-dasar pembuatan antarmuka dengan Flutter, mulai dari struktur project, widget, hingga menjalankan aplikasi di perangkat atau emulator.

## Fitur Utama

- Menampilkan halaman profil mahasiswa dengan nama dan mata kuliah.

## Stack Teknologi

- **Flutter** — framework UI multi-platform.
- **Dart** — bahasa pemrograman yang digunakan Flutter.

## Cara Menjalankan

Aplikasi dapat dijalankan di emulator, simulator, atau perangkat fisik. Untuk mengecek kesiapan environment:

```bash
flutter doctor
```

Pastikan Flutter SDK sudah terpasang, jalankan perintah berikut di dalam folder `my_first_app`:

```bash
flutter pub get # Untuk mendownload packages
flutter run # Untuk menjalankan aplikasi
```

## Hasil yang Dicapai

- Aplikasi Flutter pertama berhasil dibuat dan dijalankan.
- Memahami kode dasar dart.
- Mengenal alur kerja pengembangan mobile dengan Flutter sebagai fondasi untuk minggu-minggu berikutnya.
